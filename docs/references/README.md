Исходные советы владельца сохранены целиком с нормализованным форматированием. Их наличие не означает принятие всех предложенных правил.

## Что выбрано

Направление входа, ограниченная внешняя поддержка, осмысленный выход, память места, действующие персонажи с целями, предметы как возможности, право на погружение.
Защита уравновешивается полезной мобильностью. Предлагаемые числа требуют проверки.
Хранитель и советники помогают по желанию. Подсказки и краткость управляются игроком.

## Что переработано

Нет обязательного последнего уровня 3×3, бесконечных проекций/наград и автоматического создания существ из ничего.
Не определять возраст, интеллект, убеждения и мораль по кликам. Адаптация не переписывает законы мира.
Три масштаба не ограничивают глубину. Быстрое решение не гарантируется там, где оно не определено правилами.
Движок рассчитывает факты, художественная подача их объясняет. Наличие общего набора правил не означает отсутствие авторской работы.

Точные требования для новой реализации: [основной референс](../MASTER-REFERENCE.md). Старые эксперименты и их тестовые результаты не импортированы.
