# Apeiron — «Право на шлях», сюжетна тестова збірка 0.2

Дата: 2026-11-10 (Europe/Kyiv). **Статус: експериментальний локальний ZIP, не канон і не інтеграція в рушій Apeiron.** Власник запропонував HTML-оболонку від DeepSeek, аби перевіряти на власному хостингу. Аудит і висновки щодо вихідного коду: docs/reviews/DEEPSEEK-SHELL-REVIEW-2026-11-10.md.

## Рішення щодо демоверсії
- Старий `prototypes/last-lantern` не змінювати.
- Замість мотузок, масла, човна і пакунків створено **окремий сюжетний testbed** із новим (не запозиченим) скінченним детермінованим engine, у якому три стратегічні рішення визначають розподіл права проходу між містом, Терасами, Вежею і Глибинами.
- Візуальна ідея: пергамент, карта переходів, книга-історія, вибір дій, хроніка; на вертикальному телефоні спершу показуються сюжет і рішення, карта нижче.
- Сюжетний конфлікт: дві делегації з однаковими печатками, документ з підписом героя, взаємовиключні поверхневі шляхи, можливий вкладений обхід, політичне право його закривати.
- Вибір дає чотири результати: контроль міста, спільна угода з почерговим доступом, незалежний шлях Глибин, невирішена суперечка. Не стверджувати, що це вже самостійна симуляція фракцій або нескінченних світів.
- Мова гравця UA/EN; немає мережевих залежностей; локальне збереження ключем `apeiron.storytest.v2`, не перекриває Last Lantern.
- Архів для користувача в **поточному чаті**: `Apeiron-Strategic-Shell-v0.2.zip`, каталог `apeiron-story` має `index.html`, `style.css`, `engine.js`, `view.js`; тестові файли в `tests`. Дистрибутивні файли створені у середовищі розмови, **не збережені як GitHub source files у цьому коміті**. Публічне посилання sandbox у документації не додавати, адже воно не є постійним GitHub URL.

## Перевірки
- `node --check` для `engine.js` та `view.js`: без синтаксичних помилок.
- `node --test` — 2 набори пройшли; перебрано всі легальні гілки трьох рішень, 4 закінчення, save/replay і відмови illegal action.
- Headless Chromium: перевірено рендеринг, початкові три варіанти, наступний етап, перемикання UA/EN, відкриття незалежного маршруту, завершення, відсутність JS exceptions, відсутність горизонтального overflow при 390 та 1280 px.
- Browser-контекст у середовищі тестів обмежив доступ до localStorage для about:blank, тому реальний browser reload/persistence та Safari **НЕ засвідчені**; replay окремо перевірено вузловими тестами.
- На хостингу папки 755 / файли 644, усі ресурси відносні, зовнішніх шрифтів/зображень немає.

## Що тестувати на iPad
1. Розпакувати ZIP і перенести `apeiron-story/` цілком на хостинг, відкривати каталог по HTTPS.
2. Переконатися, що кнопки рішення доступні без горизонтального прокручування в портреті.
3. Пройти поверхневий і глибинний варіанти; порівняти наслідки.
4. Після першого рішення оновити сторінку: чи зберігся стан, чи не з'явилися некоректні тексти.
5. Перемкнути UA/EN, перевірити всі підписи, фінали та кнопку ↺.
6. Оцінити, чи виникає бажання дізнатися правду про підпис і повернутися до інших світів.

## Принцип наступної ітерації
Якщо зацікавленість є, працювати над характером NPC, нелінійними наслідками та справжньою симуляцією законних переходів. Не робити вигляд, ніби фіксована трьохкрокова історія вже є універсальним генератором пригод. Вибір фінального сюжету залишається за власником.
