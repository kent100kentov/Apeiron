# Apeiron · Останній ліхтар / The Last Lantern — 0.1.0

Самостоятельная игровая демоверсия, написанная заново. Один автономный HTML, оригинальные встроенные SVG-иллюстрации и портреты, UA/EN. Нет сетевых шрифтов, ассетов, библиотек и сборщика для запуска.

## Загрузка на хостинг

Запустить `python build.py`. ZIP содержит папку `apeiron/` с `index.html`.
Загрузить эту папку на хостинг либо положить её index.html в выбранный каталог.
Файл имеет права 644, папка 755. Внешних зависимостей и Service Worker нет.
Альтернатива — взять готовый `dist/index.html`. Для старого кэша открывать новую папку либо URL с новой версией.

Состояние хранится в localStorage данного браузера и сайта. В приватном/ограниченном режиме браузер может запретить запись; игра показывает сообщение.
При изменении домена/браузера сохранение автоматически не переносится.

## Что играет

Герой ищет письмо, написанное его собственным почерком. На острове — перевозчик Остап, мастер Мира, маяк и верба.
Масло и мотузка имеют несколько применений. Човен отходит по игровым ходам; отсутствие игрока ничего не расходует.
Есть два кубика для рискованного действия и гарантированный способ с ценой.
Маяк меняет внешний срок и открывает возможность во внутреннем саду.
Внутри вербы — перемещение по сетке с меняющимися запретными линиями, выбор судьбы лінзы и возврат с последствием для острова.
Кольцо меняет соседство мест, сохраняя их ID и состояние.
Пять достижимых исходов. Журнал и завершение показывают, что изменилось.

## Статус

Это короткая авторская демоверсия для проверки интереса, не законченная универсальная система и не реализация всего глоссария «Переправа».
У неё отдельные предложенные правила и тесты. Один внутренний мир, без бесконечного генератора, мультиплеера, боевой системы и обещания окончательного баланса.
Числовые сроки 8/12 и правила сада — экспериментальные параметры.
Звук в этой версии не добавлялся.
Из старого предоставленного HTML код не заимствован.

## Исходники

`engine.js` — чистый переход состояния, доступные действия, сроки, ресурсы и внутренний мир.
`view.js` — текст UA/EN, иллюстрации SVG, управление и сохранение.
`shell.html`, `style.css` — структура и оформление.
`build.py` — автономный HTML и ZIP с правами.
`test.mjs` — проверки механики; запуск `node test.mjs`.
`TEST-RESULTS.json` — результат последнего запуска.

Браузерная проверка: завершена ветка перевозчика, переключение языков, перезапуск, localStorage после reload и ширина 390px в браузере тестовой среды. Нативный iOS/iPadOS Safari не запускался.
Для Safari применены обычный script, touch targets, viewport-fit, safe-area и fallback высоты; фактическая совместимость устройства ещё требует проверки.
